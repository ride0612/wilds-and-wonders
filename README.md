# 绝不认书：次元回响

**穿越书页，带着新的可能回到现实。**

一款可离线运行的剧情编队自动战斗 Demo。你是现代平行世界的年轻人，在宇宙势力“寂蚀群”入侵地球后加入“折页计划”，通过叙事载体进入其他次元，将亲历中获得的物品、知识和协作机会带回现实。

“绝不认书”取“认书／认输”的双关：读过故事，仍要观察眼前的人，并亲自作出选择。

> 本仓库沿用原项目地址 `wilds-and-wonders`。当前版本已更换名称、世界观与第一章剧情，并移除运行时的服务器、登录和注册依赖。

## 直接开始

1. [下载当前源码 ZIP](https://github.com/ride0612/wilds-and-wonders/archive/refs/heads/main.zip)，或克隆仓库：

   ```sh
   git clone https://github.com/ride0612/wilds-and-wonders.git
   ```

2. 完整解压，保留 `assets/` 与全部脚本、样式文件。
3. 使用桌面浏览器打开根目录的 **`index.html`**。
4. 选择主角形象，从大厅进入“次元远征”。

**无需启动服务器、注册账号或安装 Node.js，即可使用浏览器版。** 路明非、楚子航、诺诺、凯撒、芬格尔、零、沈岚、方晴全部开放。进度、编队、设置和同行选择保存在本机。

当前源码包含最新剧情；GitHub Releases 中此前的 v0.9 安装包属于旧版本。需要新桌面版时，请按下方说明构建。

## 战斗画面

战场采用本地 Three.js / WebGL 2 渲染。人物为约 7.4 头身的风格化轻量网格，拥有独立四肢、头部、衣摆和装备；不是贴图棋子，也不是写实扫描模型。普通遭遇战中人物会沿地面路径移动；守点关卡保留原有站位规则，人物在各自防守位置转向攻击。

默认高画质，可在设置中切换均衡或流畅模式。战斗中网格默认淡出，战前保留部署提示。无需联网或服务器；设备无法使用 WebGL 2 时会切到正常比例的 2D 兼容画面。

[八位模型与制作说明](assets/models/README.md) · [模型几何预览](assets/models/model-preview.png)（离线几何预览，非游戏截图）

剧情本轮重写了 86 段对白，新增 8 段凯撒、零等人的交流，并改写三条归航尾声：减少重复的条款式说教，通过动作、停顿和日常细节表现性格。

## 第一章的四个篇章

- **现实篇 · 门从何处来**：主角在旧书店街区救援中发现穿越能力，加入折页计划，完成首次锚定。
- **相遇篇 · 书页之外的人**：进入卡塞尔学院，与当地人物相处，调查异常站台，取得第一份屏蔽材料。
- **并肩篇 · 两个世界的名字**：现实危机通过通信持续传来，两边协作核验消息，识破伪造的归途。
- **归航篇 · 绝不认书**：修复返航路线，清除入侵索引，邀请一位同行者，并把成果安全带回现实。

路明非、诺诺、楚子航有不同的邀请回应、抵达现实反应、客房对话、晚饭交流与次日约定。确认邀请后，本存档的同行者固定；自动播放和跳过剧情不会代替玩家作选择。

## 存档与玩法边界

- 新剧情使用独立存档，从现实救援开篇开始。旧版本地存档没有删除，也不会自动转成新章进度。
- 浏览器文件入口与桌面 WebView2 的存档不共用。建议固定使用同一浏览器和同一路径；清除浏览器数据会清除对应存档。
- 八位战斗角色全部开放，允许自由编队；剧情出场以当前场景为准。战场上的人物用双脚移动、转身和攻击，网格只是报位标记。章末仍只邀请一位同伴返回现实。
- 旧进度、编队位置和同行选择继续兼容。旧抽卡存档不再读取，招募券、星尘与随机装备不再影响战斗。
- 目前没有多人匹配、传统自走棋商店经济、棋子合星与赛季排名。
- 漫画、电影等后续次元已纳入故事大纲，尚未制作成可玩章节。
- 账号服务器与抽卡服务已停用；`server/` 中的旧启动入口仅提示打开离线游戏，本地历史数据不作删除。

## Windows 桌面构建

在 Windows PowerShell 中，从项目根目录运行：

```powershell
./build.ps1 -OutputFolder release/WildsAndWonders-Offline
```

运行条件：Windows x64、.NET Framework 4.6.2 或更高版本、Microsoft Edge WebView2 Runtime。构建脚本使用系统的 .NET Framework 编译器；首次构建需要下载 WebView2 SDK，或复用本机已有的 SDK 文件。

构建产物：

- `release/WildsAndWonders-Offline/绝不认书.exe`
- 同目录的 `game/`、WebView2 DLL、使用说明与第三方声明
- `release/绝不认书-Windows-x64.zip`

`WildsAndWonders.exe` 是同一构建的兼容入口。分发时应完整打包资源与 DLL。构建过程不再打包 Node.js 或账号服务器。

## 开发与验证

测试和剧本导出使用 Node.js；当前开发验证环境为 Node.js 24。

```sh
node test.cjs
node narrative-test.cjs
node battle3d-test.cjs
node scripts/export-story.cjs
```

- `test.cjs`：战斗、20 关模拟、80 组四人阵容遭遇战、技能与防御规则、剧情流程、角色特写与全角色开放。
- `narrative-test.cjs`：页面元素与文案键、阅读断点、三种同行分支、邀请锁定、跳过／自动播放防代选、携行档案、存档恢复、人物素材绑定与抽卡移除。
- `battle3d-test.cjs`：正常比例网格、四组关节动画、GLB 数据范围、三维投影与选人、重开与暂停、画质切换、特效释放、WebGL 失效兼容路径。使用渲染器替身测试场景逻辑，不代表 GPU 画面验收。
- `scripts/export-models.cjs`：导出与运行时相同的八套 GLB，含待机／行走／攻击／技能动画。运行时直接创建网格，无需读取 GLB 或联网。
- `scripts/export-story.cjs`：从当前游戏数据重新导出完整中文剧本。

上述自动化测试已通过，桌面程序已成功编译。最近一次开发环境中，Windows 应用程序控制阻止了新 EXE 启动，内置浏览器也不允许访问 `file://`，因此**新剧情界面与 WebGL 战斗画面的真实窗口视觉验收尚未完成**。该限制不等同于实际桌面启动测试通过。

在允许启动该程序的测试环境中，可运行 `绝不认书.exe --smoke-test`，使用独立测试档案检查对话布局、三条分支与重载存档。详见 [桌面开发说明](desktop/README.md)。
