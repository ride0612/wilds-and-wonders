# 绝不认书：次元回响

**穿越书页，带着新的可能回到现实。**

一款可离线运行的剧情编队自动战斗 Demo。你是现代平行世界的年轻人，在宇宙势力“寂蚀群”入侵地球后加入“折页计划”，通过叙事载体进入其他次元，将亲历中获得的物品、知识和协作机会带回现实。

“绝不认书”取“认书／认输”的双关：读过故事，仍要观察眼前的人，并亲自作出选择。

> 本仓库沿用原项目地址 `wilds-and-wonders`。当前版本已更换名称、世界观与第一章剧情，并移除运行时的服务器、登录和注册依赖。

游戏正在改用 Godot 4 重新开发，目前完成了入场界面、大厅、成员档案、作战关卡图与自走棋战斗（20 节全部可玩）；剧情对话尚未移植。运行方法与结构见 [godot/README.md](godot/README.md)。

## 直接开始

1. [下载当前源码 ZIP](https://github.com/ride0612/wilds-and-wonders/archive/refs/heads/main.zip)，或克隆仓库：

   ```sh
   git clone https://github.com/ride0612/wilds-and-wonders.git
   ```

2. 完整解压，保留 `assets/` 与全部脚本、样式文件。
3. 使用桌面浏览器打开根目录的 **`index.html`**。
4. 选择主角形象，从大厅进入“次元远征”。

**无需启动服务器、注册账号或安装 Node.js，即可使用浏览器版。** 博丽灵梦、雾雨魔理沙、红美铃、琪露诺、魂魄妖梦、八意永琳、芙兰朵露、十六夜咲夜全部开放。进度、编队与设置保存在本机。

当前源码包含最新剧情；GitHub Releases 中此前的 v0.9 安装包属于旧版本。需要新桌面版时，请按下方说明构建。

## 自走棋战斗

原有的 8×6 棋盘战斗已替换为自走棋（规则移植自配套的 Godot 自走棋原型 `autochess_demo`，并加入剧情角色与分波关卡）。每关进入时：

1. **备战**：首次抵达一关获得 5 金币 + 利息（每 10 金币 +1，最多 5）。点击招募终端的卡片购买棋子到备战席，拖到棋盘下方四行部署；部署上限等于等级。D 刷新（2 金币）、F 购买 4 经验（4 金币）、拖回商店或悬停按 E 出售。三个相同棋子自动合成 2 星，再三个合成 3 星。
2. **交战**：空格开战，棋子自动寻敌、移动、普攻回蓝、满蓝施法。分波关卡清空所有波次才算胜利。
3. **结算**：胜利 +1 金币并进入战后剧情；失败扣除终端完整度、发放重整补给（逐次递减）后重打。完整度归零只会“过载”：金币减半并重置完整度，不删除进度。已通关的关卡可重温，重温不影响经济。

进度（金币、等级、经验、备战席、棋盘、商店锁定、已选强化、已发放补给）与剧情一起保存在本机。

## 战斗画面

战场采用本地 Three.js / WebGL 2 渲染，并自带泛光后期（亮部提取 + 四级模糊 + ACES 色调映射 + 暗角）。

- **人物**：19 套程序生成的蒙皮模型，约 7.5 头身。每人一次合并为约 4 个绘制批次：卡通分层光照、随视距保持粗细的描边、菲涅尔边缘光、自发光装备线条，以及按角色绘制的动漫面部贴图（瞳色、眼线、眉形）。发型（短发、乱发、波波头、长发、马尾、双马尾、麻花辫、兜帽、卷发）、外套下摆、马尾与围巾都有独立骨骼和二阶摆动。
- **动作**：待机呼吸、按位移驱动的奔跑步态、按武器分类的攻击（刀剑挥砍、双持交替、重拳、枪械瞄准与后坐、法杖前推、盾击）、施法高举、受击后仰、眩晕摇晃、阵亡跪倒淡出与胜利举武器。
- **敌人**：寂蚀群使用黑曜石外壳与红色裂纹自发光；相位拟态会复制我方人物外形；四个首领各有独立造型与动作。
- **特效**：刀光、弹道与拖尾、贯穿光束、落点预警圈、陨星、火柱、冲击环、粒子爆散、护盾能量罩、施法补光、震屏与打击停顿；跳字、血条（护盾段、每 300 生命刻度）、法力条与星级显示在 HUD 层。
- **场景**：悬浮平台棋盘（着色器绘制的战术网格、悬停格高亮、敌我半场与分界线）、六边形备战席、四个篇章各自的天空、城市剪影与发光窗带、浮空碎块、体积光柱和天气粒子。
- **卡面头像与立绘**：招募终端、输出统计、角色档案与对话里的头像都由运行时的 3D 模型渲染，与战场人物一致。

默认高画质，可在设置中切换均衡（较低分辨率与泛光）或流畅（无阴影、无描边、无泛光）。无需联网或服务器。设备无法使用 WebGL 2 时会显示提示，战斗仍会自动结算。

## 存档与玩法边界

- 本版使用新的剧情存档版本：旧的阅读断点与同行选择不再读取，关卡进度与自走棋进度保留。
- 浏览器文件入口与桌面 WebView2 的存档不共用。建议固定使用同一浏览器和同一路径；清除浏览器数据会清除对应存档。
- 八位幻想乡角色作为招募终端里的棋子出现（与其他棋子共享卡池）。
- 旧版的固定五人编队不会转换为自走棋棋子，读取旧档时从当前关卡的招募开始。旧抽卡存档不再读取。
- 自走棋为单人剧情模式：没有多人匹配、对手玩家、选秀轮与赛季排名。
- 漫画、电影等后续次元已纳入故事大纲，尚未制作成可玩章节。
- 账号服务器与抽卡服务已停用；`server/` 中的旧启动入口仅提示打开离线游戏，本地历史数据不作删除。

## Windows 桌面构建

在 Windows PowerShell 中，从项目根目录运行：

```powershell
./build.ps1 -OutputFolder release/WildsAndWonders-Offline
```

运行条件：Windows x64、.NET Framework 4.6.2 或更高版本、Microsoft Edge WebView2 Runtime。构建脚本使用系统的 .NET Framework 编译器；首次构建需要下载 WebView2 SDK，或复用本机已有的 SDK 文件。

构建产物：

- `release/WildsAndWonders-Offline/绝不认书.exe`
- 同目录的 `game/`、WebView2 DLL、使用说明与第三方声明
- `release/绝不认书-Windows-x64.zip`

`WildsAndWonders.exe` 是同一构建的兼容入口。分发时应完整打包资源与 DLL。构建过程不再打包 Node.js 或账号服务器。

## 开发与验证

测试和剧本导出使用 Node.js；当前开发验证环境为 Node.js 24。

```sh
node autochess-test.cjs
node narrative-test.cjs
node scripts/export-story.cjs
```

- `autochess-test.cjs`：经济与利息、商店刷新、三合一与满席合成、部署上限与换位、出售返还、羁绊档位、存档往返与非法存档过滤、失败补给与过载、分波关卡、19 名棋子的技能释放，以及机器人跑完 20 关的胜率统计。
- `narrative-test.cjs`：页面元素与文案键、20 节占位剧情、最后一节可直接完成、存档恢复、八位角色的立绘与 3D 造型、剧情角色可招募，以及每位剧情角色的无画面战斗。
- `scripts/export-story.cjs`：从当前游戏数据导出第一章剧本。

在允许启动该程序的测试环境中，可运行 `绝不认书.exe --smoke-test`，使用独立测试档案检查对话布局与重载存档。详见 [桌面开发说明](desktop/README.md)。
