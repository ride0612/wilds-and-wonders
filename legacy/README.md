# 旧版战斗模块（已停用）

这些文件是替换为自走棋之前的 8×6 棋盘战斗、守点规则、关节模型、20 关场景与对应测试。`index.html` 与 `build.ps1` 已不再加载或打包它们，仅保留作参考：

- `game.js`（旧版）、`arena.js`、`defense.js`、`skill-fx.js`：旧战斗规则与 2D 兼容画面
- `character-models.js`、`battle3d.js`、`battle-scenery.js`：旧 3D 关节模型、战场与场景
- `test.cjs`、`battle3d-test.cjs`、`scenery-test.cjs`：旧战斗测试
- `scripts/`：旧模型 GLB 导出与几何预览脚本

当前战斗见根目录的 `autochess-*.js` 与 `hero-models.js`。
