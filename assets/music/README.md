# 远境传说 · v0.8 原创配乐

配乐由原创音符编排与代码合成生成：加法合成模拟钢琴、钟音、弦乐铺底和简单打击声，再加入循环延迟。不是实录乐队、真人演奏或音乐模型生成的音频，也不使用现成小说、动画或游戏配乐。

交付为 22,050 Hz、16 位 PCM、双声道 WAV。每首采用 16 小节循环结构，约 31～52 秒；尾音以环形延迟写回开头，适合反复播放。

`music.js` 按大厅、章节和战斗类型选择曲目，切换时约 1.2 秒淡入淡出。首次点击或按键后播放，页面进入后台时暂停。扩展提供音乐开关、音量与当前曲名，中英日均有文本。音乐设置保存在当前浏览器本地存储，不随账号同步。当前没有角色配音。

## 从源码重新生成

在**项目根目录**运行，无需额外依赖：

```powershell
node assets/music/compose.cjs
```

脚本覆盖 `assets/music` 下上述 8 个 WAV 和 `manifest.json`。固定音符与确定性合成参数可重复生成相同素材；修改 `compose.cjs` 的曲目定义可调整速度、旋律、和弦和音色。`manifest.json` 记录采样率、声道、帧数与时长。重新生成后需重新构建 Windows 包，才能将音乐更新交付玩家。

源码中 `music.js` 负责播放，`assets/music/compose.cjs` 负责生成，`desktop/smoke-v8.js` 在真实 WebView2 中检查八首音乐的加载和解码。
