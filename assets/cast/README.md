`*-portrait.png` 用于大厅、角色卡、档案、剧情左侧人物和技能特写；`*-battle.png` 用于 Canvas 战斗棋子。保留真实 PNG alpha。角色脚底为程序动作原点，绘制时按原图宽高比缩放；移动、呼吸、攻击、受击由程序处理。它们是具有立体渲染风格的 **2D 战斗精灵**，不包含 GLB/FBX、可编辑网格或骨骼绑定。

稳定的旧角色 ID 仅用于兼容存档，显示名、人物资料、技能和资源均由 `characters.js` 中的剧情角色映射提供。抽卡及星级门槛已移除，所有角色直接可用；剧情的一个真人返航席位仍单独管理。

画面逐张检查了脸部、服装与完整轮廓；透明通道与资源引用由程序检查。当前受限环境尚未完成真实游戏窗口的视觉验收。
